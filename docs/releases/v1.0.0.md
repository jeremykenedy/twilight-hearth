# Twilight Hearth 1.0.0

First stable release of the continuously animated fireplace screensaver.

## Included

- Original procedural flame, ember, glowing-log, and room-light animation.
- Traditional brick, natural stone, and modern dark surrounds.
- Flame intensity, ember count, movement speed, room lighting, and random-selection controls.
- A remote-friendly settings screen, app preview, DreamService, and discoverable settings provider.
- A guided ADB installer that verifies the latest release checksum and a confirmed uninstall path.
- Apache-2.0 license and no app ads, analytics, tracking, reporting, or runtime network access.

## Compatibility

Android 6.0 (API 23) or later on devices exposing Android DreamService screensaver controls. The app was installed and visually checked on Android TV emulator 5570 at 1920x1080. Physical Fire TV, Android TV, and Google TV hardware are not verified for this release.

## Install and upgrade

Run `python3 install.py --serial DEVICE` to download the signed APK from this repository's latest release, verify the published SHA-256 checksum, and install it. To install from a local build, pass `--apk build/twilight-hearth.apk`. An update keeps the package and release signing certificate stable. The installer does not change screensaver selection or system timers.

To install manually, download `twilight-hearth.apk` and `twilight-hearth.apk.sha256` from the release and run `shasum -a 256 -c twilight-hearth.apk.sha256` before installing.

## Breaking changes and commands

There are no earlier releases and no breaking changes. The installer supports `--serial`, `--apk`, `--yes`, and `--uninstall`; unattended removal additionally requires `--force`.
