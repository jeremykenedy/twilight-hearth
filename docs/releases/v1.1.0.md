# Twilight Hearth 1.1.0

Recorded wood fire and photographed brick, stone and modern slate surrounds replace the painted fireplace. The fire runs offline with adjustable exposure, playback speed, embers, room lighting and quiet whole-scene drift.

## Upgrade guide

Update the existing 1.0.0 package in place using its production signer. Android API 23+, OpenGL ES 2 and H.264 decoding are required. All six existing preference keys and accepted values remain supported, and the minimum API remains 23. No accounts, runtime downloads, migrations, environment changes or system-timer changes are needed.

Download `twilight-hearth.apk` and `twilight-hearth.apk.sha256`, then run:

```sh
shasum -a 256 -c twilight-hearth.apk.sha256
python3 install.py --serial SERIAL --apk twilight-hearth.apk
```

The guided installer can fetch and verify the latest stable release with `python3 install.py --serial SERIAL`. Open the app, choose a surround and preview it with the remote, then use Back to return. Select its DreamService in supported platform screensaver settings or through Fire TV Toolkit for idle use. The installer does not change selected screensaver, timers or OS update settings.

Keep a trusted signed APK and preserve signer continuity. A different signer cannot update the same package; uninstalling to bypass that mismatch deletes local settings. Selecting another screensaver provides a reversible fallback. Android may refuse a version-code downgrade to 1.0.0; uninstalling to downgrade deletes preferences. Scripted removal requires `--uninstall --yes --force`.

## Breaking changes

Package, signer, minimum API, provider endpoints and all six preference keys remain stable. The replacement requires OpenGL ES 2 and H.264 decoding; devices lacking those capabilities cannot use it. The visual renderer changes: intensity now adjusts recorded-flame exposure without resizing logs, and movement changes actual video playback to 0.65x, 1x or 1.55x. Existing values map to the corresponding low/natural/high and slow/natural/fast choices. No stored-value migration is required.

## Major changes

- Recorded 1920x1080 wood fire in a 29.25-second loop.
- Photographed brick, natural stone and modern dark slate surrounds, with normal-map material detail and flickering reflected light.
- Recorded-flame exposure, actual playback speed, floating embers, room lighting and scene drift.
- Preserved native remote settings, per-setting Random and randomize-all, protected DreamService and stable host provider.

## Minor changes and fixes

- Full source credits and Apache application license bundled and readable offline through native settings.
- Corrected 100 percent Java line/branch enforcement and actual formatter targets; installer coverage also enforces 100 percent.
- Current native previews and animated desktop/mobile themed banners with reduced-motion alternatives.
- No application network permissions, analytics, tracking or third-party runtime dependencies.
